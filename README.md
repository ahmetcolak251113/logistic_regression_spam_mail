Connects to an email account via IMAP and fetches the latest emails.

- Logs into the user's inbox using the provided credentials.
- Retrieves the subject and body of the all emails.
- Returns a list of dictionaries, each containing 'subject' and 'body'.

Supported email providers:
- Gmail (imap.gmail.com)
- Hotmail/Outlook (imap-mail.outlook.com)
